# CT240 Front-End

Dự án giao diện người dùng cho môn học CT240.

## Công nghệ sử dụng

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Cấu trúc thư mục

- `src/assets`: Tài nguyên hình ảnh, media
- `src/pages`: Các trang giao diện
- `src/router`: Cấu hình định tuyến
- `src/services`: Gọi API và kết nối Backend
- `src/store`: Quản lý trạng thái (state management)
- `src/types`: Định nghĩa kiểu dữ liệu TypeScript
- `src/ui`: Layouts và các component dùng chung
- `src/utils`: Các hàm tiện ích hỗ trợ

## Hướng dẫn cài đặt và khởi chạy

Yêu cầu môi trường: Node.js (phiên bản 18 trở lên).

1. Cài đặt các gói phụ thuộc:
```bash
npm install
```

2. Khởi chạy môi trường phát triển:
```bash
npm run dev
```

3. Xây dựng dự án:
```bash
npm run build
```
